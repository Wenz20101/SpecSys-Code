To solve the problem of **counting the number of substrings with the sum of digits equal to their length**, we can approach it as follows:

### Problem Breakdown:
- A **substring** is a contiguous sequence of characters within a string.
- For each substring, we need to:
  1. Compute the **sum of its digits**.
  2. Compute the **length** of the substring.
  3. Check if the **sum of digits equals the length**.

### Example:
For the string `"121"`, the substrings are:
- `"1"` → sum = 1, length = 1 → match ✅
- `"12"` → sum = 1+2 = 3, length = 2 → no match ❌
- `"121"` → sum = 1+2+1 = 4, length = 3 → no match ❌
- `"2"` → sum = 2, length = 1 → no match ❌
- `"21"` → sum = 2+1 = 3, length = 2 → no match ❌
- `"1"` → sum = 1, length = 1 → match ✅

So, total valid substrings = 2.

---

### Python Function:

```python
def count_substrings_with_sum_equal_to_length(s):
    count = 0
    n = len(s)
    
    for i in range(n):
        current_sum = 0
        for j in range(i, n):
            current_sum += int(s[j])
            if current_sum == (j - i + 1):
                count += 1
                
    return count
```

### How it works:
- We iterate over all possible starting indices `i`.
- For each `i`, we iterate over all possible ending indices `j` (from `i` to `n-1`).
- For each substring `s[i:j+1]`, we compute the sum of digits and compare it with the length of the substring (`j - i + 1`).
- If they are equal, we increment the count.

---

### Example Usage:

```python
s = "121"
print(count_substrings_with_sum_equal_to_length(s))  # Output: 2
```
