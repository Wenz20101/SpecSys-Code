Here's a Python function that removes characters from the first string which are present in the second string:

```python
def remove_chars_from_first_string(str1, str2):
    # Create a set of characters from the second string for fast lookup
    chars_to_remove = set(str2)
    
    # Use a list comprehension to filter out characters in str1 that are in chars_to_remove
    result = ''.join([char for char in str1 if char not in chars_to_remove])
    
    return result
```

### Example usage:

```python
str1 = "hello world"
str2 = "lo"

print(remove_chars_from_first_string(str1, str2))
```

### Output:
```
he wrd
```

### Explanation:
- The characters `'l'` and `'o'` from `str2` are removed from `str1`.
- The resulting string is `"he wrd"`.
