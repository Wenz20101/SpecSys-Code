To determine whether a number is divisible by 11, we can use the **rule of divisibility by 11**:

> A number is divisible by 11 if the **difference between the sum of the digits in the odd positions** and the **sum of the digits in the even positions** is either 0 or a multiple of 11.

For example:
- For `1212112`, the digits in odd positions are `1, 1, 1, 2` (positions 1, 3, 5, 7), and the digits in even positions are `2, 2, 1` (positions 2, 4, 6).
- Sum of odd positions: `1 + 1 + 1 + 2 = 5`
- Sum of even positions: `2 + 2 + 1 = 5`
- Difference: `5 - 5 = 0` → divisible by 11

Here is the Python function that implements this logic:

```python
def is_Diff(n):
    n_str = str(n)
    odd_sum = 0
    even_sum = 0

    for i in range(len(n_str)):
        digit = int(n_str[i])
        if i % 2 == 0:  # 0-based index, so odd positions are 0, 2, 4...
            odd_sum += digit
        else:
            even_sum += digit

    return (odd_sum - even_sum) % 11 == 0
```

### Example usage:

```python
print(is_Diff(12345))    # False
print(is_Diff(1212112))  # True
print(is_Diff(1212))     # False
```

### Explanation of the test cases:
- `12345`: Difference is `1 + 3 + 5 - (2 + 4) = 9 - 6 = 3` → not divisible by 11 → `False`
- `1212112`: Difference is `1 + 1 + 1 + 2 - (2 + 2 + 1) = 5 - 5 = 0` → divisible by 11 → `True`
- `1212`: Difference is `1 + 1 - (2 + 2) = 2
