Here's a Python function that solves the given MBPP (Meta's Basic Programming Problems) task:

### **Task Explanation:**
You are given a string, and you need to:
1. Sum the ASCII values of all characters in the string.
2. Take the sum modulo 26.
3. Convert the resulting number (0–25) to a corresponding character in the alphabet (`a` to `z`).

### ✅ **Python Function:**

```python
def get_Char(s):
    total = sum(ord(char) for char in s)
    mod_value = total % 26
    return chr(ord('a') + mod_value)
```

### 🔍 **Explanation:**
- `ord(char)` gets the ASCII value of each character.
- `sum(...)` adds all the ASCII values.
- `total % 26` ensures the result is between 0 and 25.
- `chr(ord('a') + mod_value)` maps the number to a letter from `'a'` to `'z'`.

### ✅ **Test Cases:**

```python

```
