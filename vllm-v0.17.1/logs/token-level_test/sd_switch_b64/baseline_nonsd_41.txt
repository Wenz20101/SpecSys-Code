Here's a Python function that solves the given MBPP (Minimum By Python Problem) task:

### **Task Explanation:**
You are given a list of tuples, where each tuple contains a string and a number. You need to return the **first value** (the string) of the tuple that has the **smallest second value** (the number).

---

### ✅ **Python Function:**

```python
def index_minimum(lst):
    # Find the tuple with the smallest second value
    min_tuple = min(lst, key=lambda x: x[1])
    # Return the first value of that tuple
    return min_tuple[0]
```

---

### 🔍 **Explanation:**
- `min(lst, key=lambda x: x[1])` finds the tuple with the **smallest second element**.
- `min_tuple[0]` returns the **first element** of that tuple, which is the string you're looking for.
