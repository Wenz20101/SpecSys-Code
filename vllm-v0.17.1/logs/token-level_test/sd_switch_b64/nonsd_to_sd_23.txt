To determine whether a number can be represented as the **difference of two squares**, we can use the following mathematical insight:

A number `n` can be expressed as the difference of two squares if and only if **it is not congruent to 2 modulo 4**. In other words:

- If `n % 4 == 2`, then it **cannot** be expressed as the difference of two squares.
- Otherwise, it **can** be expressed as the difference of two squares.

### Explanation:
The difference of two squares is:
```
a² - b² = (a - b)(a + b)
```
So, `n = (a - b)(a + b)`. Both `(a - b)` and `(a + b)` must be integers of the same parity (both even or both odd), so their product must be either odd or divisible by 4.

Thus, numbers that are **2 mod 4** cannot be expressed as the difference of two squares.

---

### ✅ Python Function:

```python
def dif_Square(n):
    return n % 4 != 2
```

### ✅ Test Cases:

```python
assert dif_Square(5) == True   # 5 % 4 = 1 → True
assert dif_Square(10) == False # 10 % 4 = 2 → False
assert dif_Square(15) == True  # 15 % 4 = 3 → True
```

This function passes all the given test cases and correctly identifies whether a number can be expressed as the difference of two squares.
