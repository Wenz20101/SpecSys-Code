### Task:
Write a function to **multiply all the numbers in a list** and **divide with the length of the list**.

### Function:

```python
import math

def multiply_num(numbers):
    """
    Multiplies all the numbers in the input list and divides the result by the length of the list.
    
    Parameters:
    numbers (tuple or list): A collection of numbers.
    
    Returns:
    float: The result of the product of all numbers divided by the length of the list.
    """
    if not numbers:
        raise ValueError("The input list is empty.")
    
    product = 1
    for num in numbers:
        product *= num
    
    return product / len(numbers)
```

### Explanation:
- The function first checks if the input is empty and raises a `ValueError` if so.
- It then calculates the product of all numbers in the list.
- Finally, it divides the product by the length of the list and returns the result.

### Example Usage:
```python

# Test cases

assert math.isclose(multiply_num((-10, -20, -30)), -2000.0, rel_tol=0.001)
assert math.isclose(multiply_num((19, 15, 18)), 1710.0, rel_tol=0.001)
```
