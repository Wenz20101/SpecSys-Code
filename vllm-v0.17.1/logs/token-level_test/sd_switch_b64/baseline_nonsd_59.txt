Here's a Python function that converts a tuple of positive integers into a single integer by concatenating the digits:

```python
def tuple_to_int(t):
    """
    Converts a tuple of positive integers into a single integer.
    
    Parameters:
    t (tuple): A tuple of positive integers.
    
    Returns:
    int: The concatenated integer.
    """
    return int(''.join(map(str, t)))

# Test cases
assert tuple_to_int((1, 2, 3)) == 123
assert tuple_to_int((4, 5, 6)) == 456
assert tuple_to_int((5, 6, 7)) == 567
```

### Explanation:
- `map(str, t)` converts each number in the tuple to a string.
- `''.join(...)` concatenates the string representations.
- `int(...)` converts the resulting string back to an integer.

This function works for any tuple of positive integers as long as they are meant to be concatenated in order.
