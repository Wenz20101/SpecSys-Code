Here's a Python function that solves the MBPP task of counting the frequency of all elements in a list and returning the result as a dictionary:

```python
def freq_count(lst):
    freq = {}
    for item in lst:
        if item in freq:
            freq[item] += 1
        else:
            freq[item] = 1
    return freq
```

### Explanation:
- The function `freq_count` takes a list `lst` as input.
- It initializes an empty dictionary `freq`.
- It iterates over each element in the list:
  - If the element is already a key in the dictionary, it increments the count.
  - If not, it adds the element to the dictionary with a count of 1.
- Finally, it returns the dictionary with element frequencies.

### Example usage:
```python
print(freq_count([10,10,10,10,20,20,20,20,40,40,50,50,30]))
# Output: {10: 4, 20: 4, 40: 2, 50: 2, 30: 1}
```
