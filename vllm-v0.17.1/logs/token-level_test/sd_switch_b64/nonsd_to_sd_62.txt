To solve this problem, we can take advantage of the fact that the array is **sorted**. In a sorted array, if every element appears **exactly twice** except for one element that appears **once**, the single element will be the one that breaks the pattern of pairs.

### Key Insight:
- In a sorted array, if the array is of even length and all elements appear twice, then the array is perfectly paired.
- If there is a single element that appears once, it will be the one that is **not paired** with its neighbor.

### Strategy:
- Traverse the array in steps of 2.
- Compare each element with the next one.
- If they are not equal, the current element is the one that appears only once.
- If the loop completes without finding such an element, return the last element (which must be the single one).

Here is the Python function:

```python
def search(arr):
    n = len(arr)
    for i in range(0, n - 1, 2):
        if arr[i] != arr[i + 1]:
            return arr[i]
    return arr[-1]
```

### Explanation:
- The loop goes through the array in steps of 2.
- If `arr[i] != arr[i + 1]`, then `arr[i]` is the unique element.
- If the loop completes, the last element is the unique one (since all others were in pairs).
