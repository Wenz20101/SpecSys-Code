Here's a Python function that merges three dictionaries into a single dictionary. In case of key collisions, the **last dictionary** (third one) will overwrite the previous values, as is standard in Python dictionary updates.

```python
def merge_dictionaries_three(dict1, dict2, dict3):
    """
    Merges three dictionaries into one. In case of key collisions,
    the value from the third dictionary will overwrite the previous ones.
    
    Parameters:
    dict1 (dict): First dictionary
    dict2 (dict): Second dictionary
    dict3 (dict): Third dictionary
    
    Returns:
    dict: Merged dictionary
    """
    merged = {}
    merged.update(dict1)
    merged.update(dict2)
    merged.update(dict3)
    return merged
```

### Example Usage:

```python
# Test case 1
print(merge_dictionaries_three(
    {"R": "Red", "B": "Black", "P": "Pink"},
    {"G": "Green", "W": "White"},
    {"O": "Orange", "W": "White", "B": "Black"}
))

# Output: {'R': 'Red', 'B': 'Black', 'P': 'Pink', 'G': 'Green', 'W': 'White', 'O': 'Orange'}
```
