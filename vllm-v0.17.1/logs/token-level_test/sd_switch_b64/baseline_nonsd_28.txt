A **tetrahedral number** is a figurate number that represents a tetrahedron. The formula for the nth tetrahedral number is:

$$
T_n = \frac{n(n+1)(n+2)}{6}
$$

Here's a Python function that implements this formula:

```python
def tetrahedral_number(n):
    return n * (n + 1) * (n + 2) // 6
```

### Explanation:
- The formula `n * (n + 1) * (n + 2) // 6` computes the tetrahedral number.
- We use integer division (`//`) to ensure the result is an integer, as the formula always results in a whole number.

### Example usage with the provided tests:

```python
assert tetrahedral_number(5) == 35
assert tetrahedral_number(6) == 56
assert tetrahedral_number(7) == 84
```
