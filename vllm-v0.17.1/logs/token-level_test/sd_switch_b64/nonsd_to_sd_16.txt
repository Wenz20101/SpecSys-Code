Here's a Python function that recursively flattens a list and sums all of its elements, as required by the MBPP task:

```python
def recursive_list_sum(lst):
    total = 0
    for item in lst:
        if isinstance(item, list):
            total += recursive_list_sum(item)
        else:
            total += item
    return total
```

### Explanation:
- The function `recursive_list_sum` takes a list `lst` as input.
- It initializes a `total` variable to 0.
- It iterates over each `item` in the list:
  - If the `item` is a list, it recursively calls `recursive_list_sum` on that sublist and adds the result to `total`.
  - If the `item` is not a list (i.e., it's a number), it adds the number directly to `total`.
- Finally, it returns the `total`.

### Example Usage:
```python
print(recursive_list_sum([1, 2, [3, 4], [5, 6]]))  # Output: 21
print(recursive_list_sum([7, 10, [15, 14], [19, 41]]))  # Output: 106
print(recursive_list_sum([10, 20, [30, 40], [50, 60]]))  # Output: 210
```
