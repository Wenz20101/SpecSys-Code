Here's a Python function that solves the given MBPP (Machine-Behavioral Programming Problems) task:

### **Task Explanation:**
You are given a list of tuples and an integer `k`. You need to return a list of tuples where **all elements** in the tuple are divisible by `k`.

---

### ✅ **Python Function:**

```python
def find_tuples(list_of_tuples, k):
    """
    Returns a list of tuples from list_of_tuples where all elements are divisible by k.
    
    Parameters:
    - list_of_tuples: List of tuples containing integers
    - k: Integer divisor
    
    Returns:
    - List of tuples where all elements are divisible by k
    """
    return [t for t in list_of_tuples if all(x % k == 0 for x in t)]
```

---

### 🔍 **Explanation:**
- `all(x % k == 0 for x in t)` checks if **every element** in the tuple `t` is divisible by `k`.
- The list comprehension filters out only those tuples that satisfy the condition.
