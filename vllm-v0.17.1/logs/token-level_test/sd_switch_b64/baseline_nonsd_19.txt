Here's a Python function to check whether a given array is **monotonic** or not.

### Definition:
An array is **monotonic** if it is either entirely non-increasing or non-decreasing.

### Function:

```python
def is_Monotonic(arr):
    increasing = True
    decreasing = True

    for i in range(1, len(arr)):
        if arr[i] > arr[i - 1]:
            decreasing = False
        elif arr[i] < arr[i - 1]:
            increasing = False

    return increasing or decreasing
```

### Explanation:
- We initialize two flags: `increasing` and `decreasing` to `True`.
- As we iterate through the array:
  - If the current element is greater than the previous one, it can't be non-increasing, so we set `decreasing = False`.
  - If the current element is less than the previous one, it can't be non-decreasing, so we set `increasing = False`.
- At the end, if either `increasing` or `decreasing` is still `True`, the array is monotonic.

### Example Usage:

```python
print(is_Monotonic([6, 5, 4, 4]))  # True
print(is_Monotonic([1, 2, 2, 3]))  # True
print(is_Monotonic([1, 3, 2]))     # False
```
