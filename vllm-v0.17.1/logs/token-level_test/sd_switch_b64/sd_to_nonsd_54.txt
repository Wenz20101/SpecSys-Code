Here's a Python function that merges three lists into a single **sorted list**. The function uses Python's built-in `sorted()` function to combine and sort the lists efficiently.

```python
def merge_sorted_list(list1, list2, list3):
    """
    Merges three lists into a single sorted list.

    Parameters:
    list1 (list): First list of integers.
    list2 (list): Second list of integers.
    list3 (list): Third list of integers.

    Returns:
    list: A single sorted list containing all elements from the input lists.
    """
    return sorted(list1 + list2 + list3)
```
