Here's a Python function that checks whether all the given tuples in a list have the same length:

```python
def get_equal(tuples_list):
    # Get the length of the first tuple
    if not tuples_list:
        return True  # Empty list is considered as all tuples having equal length

    first_length = len(tuples_list[0])

    # Check if all other tuples have the same length
    for t in tuples_list:
        if len(t) != first_length:
            return False
    return True
```

### Explanation:
- The function `get_equal` takes a list of tuples as input.
- It first checks if the list is empty and returns `True` in that case (since there are no tuples to compare).
- It then gets the length of the first tuple and compares it with the length of every other tuple in the list.
- If any tuple has a different length, it returns `False`.
- If all tuples have the same length, it returns `True`.

### Example usage:
```python
print(get_equal([(11, 22, 33), (44, 55, 66)]))  # Output: True
print(get_equal([(1, 2, 3), (4, 5, 6, 7)]))    # Output: False
print(get_equal([(1, 2), (3, 4)]))            # Output: True
```
