To solve the **Bell number** problem, we need to compute the **Bell number** for a given integer `n`, which represents the number of ways to partition a set of size `n`.

### What is a Bell Number?
The **Bell number** `B(n)` is the number of different ways to partition a set of `n` elements. For example:
- `B(0) = 1` (one way to partition an empty set)
- `B(1) = 1`
- `B(2) = 2`
- `B(3) = 5`
- `B(4) = 15`
- `B(5) = 52`
- `B(10) = 115975`

### Efficient Computation of Bell Numbers
We can compute Bell numbers using **Bell's triangle** or **Dobinski's formula**, but for large `n` (like 56), **Bell's triangle** is more efficient and avoids floating-point inaccuracies.

Here's a Python function that computes the Bell number using **Bell's triangle**:

```python
def bell_number(n):
    """
    Compute the nth Bell number using Bell's triangle.
    
    Parameters:
    n (int): The index of the Bell number to compute.
    
    Returns:
    int: The nth Bell number.
    """
    if n == 0:
        return 1
    
    # Initialize Bell's triangle
    bell = [[0] * (n + 1) for _ in range(n + 1)]
    bell[0][0] = 1  # B(0) = 1

    for i in range(1, n + 1):
        bell[i][0] = bell[i - 1][i - 1]  # First element of each row
        for j in range(1, i + 1):
            bell[i][j] = bell[i][j - 1] + bell[i - 1][j - 1]

    return bell[n][0]
```

### Example Usage:
```python
print(bell_number(2))     # Output: 2
print(bell_number(10))    # Output: 115975
print(bell_number(56))    # Output: 67756853206458243225814
