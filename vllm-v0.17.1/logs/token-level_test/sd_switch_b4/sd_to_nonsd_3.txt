You can solve this task by writing a Python function that uses a regular expression to check if the input string matches the pattern of sequences of lowercase letters joined with underscores.

Here's the function:

```python
import re

def text_lowercase_underscore(s):
    # Regular expression pattern: one or more lowercase letters, followed by an underscore,
    # and this pattern can repeat, but the string must end with lowercase letters.
    # The pattern should match the entire string.
    pattern = r'^[a-z]+(_[a-z]+)*$'
    return bool(re.fullmatch(pattern, s))
```

### Explanation:
- `^` and `$` ensure the pattern matches the entire string.
- `[a-z]+` matches one or more lowercase letters.
- `(_[a-z]+)*` matches zero or more occurrences of an underscore followed by one or more lowercase letters.

You can test the function with the provided test cases like this:

```python
assert text_lowercase_underscore("aab_cbbbc") == True
assert text_lowercase_underscore("aab_Abbbc") == False

```

This function will return `True` only if the string consists of sequences of lowercase letters joined by underscores, and `False` otherwise.
