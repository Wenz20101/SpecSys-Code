Here's a Python function that solves the given MBPP (Math and Programming Problem) task:

### **Task Explanation:**
We are to write a function `check(n)` that returns `True` if the number `n` is **one less than twice its reverse**, and `False` otherwise.

### **Mathematical Condition:**
We need to check:
```
n == 2 * reverse(n) - 1
```

### **Python Function:**

```python
def check(n):
    # Function to reverse a number
    def reverse_number(x):
        return int(str(x)[::-1])
    
    reversed_n = reverse_number(n)
    return n == 2 * reversed_n - 1
```

### **Testing the Function:**

You can test it with the provided test cases:

```python
assert check(70) == False
assert check(23) == False
assert check(73) == True
```

### **Explanation of Test Case `check(73)`:**
- Reverse of 73 is 37
- 2 * 37 = 74
- 74 - 1 = 73 → So, 73 is one less than twice its reverse → `True`
