### What is a Woodall Number?

A **Woodall number** is a number of the form:

$$
W_n = n \times 2^n - 1
$$

Where $ n $ is a positive integer.

So, the task is to write a function `is_woodall(n)` that returns `True` if the input number `n` is a Woodall number, and `False` otherwise.

---

### ✅ Python Function to Check if a Number is a Woodall Number

```python
def is_woodall(n):
    if n < 1:
        return False
    n += 1  # Because W_n = n * 2^n - 1 => n = W_n + 1
    for i in range(1, n):
        if i * (2 ** i) == n:
            return True
    return False
```

---

### 🔍 Explanation:

- We iterate over possible values of `i` (starting from 1).
- For each `i`, we compute `i * 2^i`.
- If this equals the input number `n`, then `n` is a Woodall number.
- We add 1 to `n` before the loop because the formula is `W_n = n * 2^n - 1`, so `n = W_n + 1`.
