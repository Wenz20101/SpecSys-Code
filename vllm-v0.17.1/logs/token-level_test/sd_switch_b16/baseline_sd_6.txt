Here's a Python function that solves the MBPP task of checking whether a given array of integers contains any duplicate elements:

```python
def test_duplicate(arr):
    """
    Check if the given array contains any duplicate elements.

    Parameters:
    arr (list): A list of integers.

    Returns:
    bool: True if there are duplicates, False otherwise.
    """
    return len(arr) != len(set(arr))
```

### Explanation:
- The function converts the list `arr` into a `set`, which automatically removes any duplicate values.
- If the length of the original list is different from the length of the set, it means there were duplicates.
- This is a simple and efficient way to check for duplicates using Python's built-in `set`.

### Example Usage:
```python
print(test_duplicate([1, 2, 3, 4, 5]))       # Output: False
print(test_duplicate([1, 2, 3, 4, 4]))       # Output: True
print(test_duplicate([1, 1, 2, 2, 3, 3, 4, 4, 5]))  # Output: True
```
