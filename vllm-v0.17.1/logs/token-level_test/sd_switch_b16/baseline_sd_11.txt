To solve the task of finding the **nth octagonal number**, we need to understand the formula for octagonal numbers.

### Formula for the nth Octagonal Number:
The nth octagonal number is given by the formula:

$$
O_n = 3n^2 - 2n
$$

This formula generates the sequence of octagonal numbers.

---

### Python Function:

Here is the Python function to compute the nth octagonal number:

```python
def is_octagonal(n):
    """
    Returns the nth octagonal number.
    
    Parameters:
    n (int): The position in the sequence of octagonal numbers.
    
    Returns:
    int: The nth octagonal number.
    """
    return 3 * n * n - 2 * n
```
