Here's a Python function that removes the **first and last occurrence** of a given character from a string:

```python
def remove_first_last_occurrence(s, char):
    # Find the first and last occurrence of the character
    first = s.find(char)
    last = s.rfind(char)

    # If the character is not found, return the original string
    if first == -1:
        return s

    # Remove the first and last occurrence
    # We need to make sure that first and last are not the same (i.e., only one occurrence)
    if first == last:
        # Only one occurrence, remove it once
        return s[:first] + s[first+1:]
    else:
        # Remove both first and last
        return s[:first] + s[first+1:last] + s[last+1:]
```

### Example usage:

```python
print(remove_first_last_occurrence("hello world", "l"))  # Output: "heo word"
print(remove_first_last_occurrence("banana", "a"))        # Output: "bann"
print(remove_first_last_occurrence("test", "x"))          # Output: "test" (char not found)
```

### Explanation:
- `s.find(char)` gives the index of the **first** occurrence.
- `s.rfind(char)` gives the index of the **last** occurrence.
- If the character is not found (`first == -1`), the string is returned as-is.
- If the character appears only once, it is removed once.
- If it appears more than once, both the first and last occurrences are removed.
