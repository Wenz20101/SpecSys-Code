Sure! Here's a Python function that appends a given list to each tuple in a list of tuples. Since tuples are immutable in Python, we'll convert each tuple to a list, append the given list, and then convert it back to a tuple if needed.

### Function Definition:

```python
def append_list_to_tuples(tuples_list, list_to_append):
    """
    Appends the given list to each tuple in the list of tuples.

    Parameters:
    tuples_list (list of tuples): The list of tuples to which the list will be appended.
    list_to_append (list): The list to append to each tuple.

    Returns:
    list of tuples: A new list of tuples with the list appended to each.
    """
    result = []
    for t in tuples_list:
        # Convert tuple to list, extend with the given list, then convert back to tuple
        new_tuple = tuple(list(t) + list_to_append)
        result.append(new_tuple)
    return result
```

### Example Usage:

```python
tuples = [(1, 2), (3, 4), (5, 6)]
append_list = [7, 8]

result = append_list_to_tuples(tuples, append_list)
print(result)
```
