You can write a Python function to check if a string represents an integer by using the `str.isdigit()` method or by attempting to convert the string to an integer using `int()` and catching exceptions.

Here's a function that does both:

### ✅ Option 1: Using `str.isdigit()` (for non-negative integers only)

```python
def is_integer(s):
    return s.isdigit()
```

**Note:** This only works for non-negative integers (e.g., `"123"` returns `True`, but `"-123"` returns `False`).

---

### ✅ Option 2: Using `try-except` block (for all integers, including negative)

```python
def is_integer(s):
    try:
        int(s)
        return True
    except ValueError:
        return False
```

**Example usage:**

```python
print(is_integer("123"))      # True
print(is_integer("-123"))     # True
print(is_integer("12.3"))     # False
print(is_integer("abc"))      # False
print(is_integer("123a"))     # False
```

---

### ✅ Option 3: Using `str.isdigit()` with sign check (for signed integers)

If you want to support negative numbers and use `isdigit()`:

```python
def is_integer(s):
    if s[0] == '-' and s[1:].isdigit():
        return True
    return s.isdigit()
```

**Example usage:**

```python
print(is_integer("123"))      # True
print(is_integer("-123"))     # True
print(is_integer("12.3"))     # False
print(is_integer("abc"))      # False
print(is_integer("123a"))     # False
```

---

### ✅ Recommended: Use the `try-except` method for the most robust solution.

```python
def is_integer(s):
    try:
        int(s)
        return True
    except ValueError:
        return False
```

This is the most general and reliable method.
