You can write a Python function to calculate the value of `a` raised to the power `b` using the built-in exponentiation operator `**`. Here's a simple function to do that:

```python
def power(a, b):
    """
    Calculate a raised to the power of b.

    Parameters:
    a (float or int): The base.
    b (float or int): The exponent.

    Returns:
    float or int: The result of a^b.
    """
    return a ** b
```

### Example usage:

```python
result = power(2, 3)
print(result)  # Output: 8
```
