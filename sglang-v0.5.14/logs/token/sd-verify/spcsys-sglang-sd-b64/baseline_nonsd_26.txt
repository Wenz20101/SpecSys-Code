You can determine whether a number is divisible by 11 using the **rule of divisibility by 11**:

> A number is divisible by 11 if the **difference between the sum of the digits in the odd positions** and the **sum of the digits in the even positions** is either 0 or a multiple of 11.

Here's a Python function that implements this rule:

```python
def is_divisible_by_11(n):
    # Convert the number to a string to iterate over its digits
    num_str = str(abs(n))  # Use absolute value to handle negative numbers

    # Initialize sums for odd and even positions
    sum_odd = 0
    sum_even = 0

    # Iterate over the digits
    for i in range(len(num_str)):
        digit = int(num_str[i])
        if i % 2 == 0:  # 0-based index, so even index (odd position)
            sum_odd += digit
        else:  # odd index (even position)
            sum_even += digit

    # Calculate the difference
    difference = sum_odd - sum_even

    # Check if the difference is 0 or a multiple of 11
    return difference == 0 or difference % 11 == 0

# Example usage:
print(is_divisible_by_11(121))   # True
print(is_divisible_by_11(123))   # False
print(is_divisible_by_11(-121))  # True
```

### Explanation:
- The function takes an integer `n`.
- It converts the number to a string and iterates over each digit.
- It adds digits at **odd positions** (0-based index: 0, 2, 4...) to `sum_odd` and digits at **even positions** (1, 3, 5...) to `sum_even`.
- It then checks if the **difference** between these two sums is 0 or divisible by 11.
