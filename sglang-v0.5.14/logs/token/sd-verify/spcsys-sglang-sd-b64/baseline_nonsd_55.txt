To solve the problem of finding the **number of numbers with an odd value** when rotating a binary string a given number of times, we need to understand what happens when you rotate a binary string.

### Problem Breakdown:

- You are given a **binary string** (e.g., `"101"`).
- You are given a number of **rotations** (e.g., `3`).
- For each rotation, the binary string is rotated left or right (usually left unless specified otherwise).
- After each rotation, the binary string is interpreted as a **binary number**.
- You need to count how many of these rotated numbers are **odd**.

### Key Observations:

- A number is **odd** if its **last digit is 1**.
- When you rotate a binary string, the **last digit** of the rotated string is the **digit that was moved to the end**.
- So, for a binary string `s`, the number of **odd numbers** after rotating it `n` times is equal to the number of times the digit `'1'` appears in the string, **if the rotation is left**.

### Example:

For binary string `"101"` and 3 rotations:

- `"101"` → `5` (odd)
- `"011"` → `3` (odd)
- `"110"` → `6` (even)

So, out of 3 rotations, 2 are odd.

### Python Function:

```python
def count_odd_rotations(binary_str, rotations):
    """
    Counts the number of odd numbers generated by rotating the binary string
    a given number of times (left rotations by default).
    
    Parameters:
    binary_str (str): The binary string to rotate.
    rotations (int): Number of rotations to perform.
    
    Returns:
    int: Number of odd numbers after rotations.
    """
    count = 0
    n = len(binary_str)
    
    for i in range(rotations):
        # Left rotate the string by 1
        rotated = binary_str[i+1:] + binary_str[:i+1]
        # Check if the last digit is '1' (i.e., the number is odd)
        if rotated[-1] == '1':
            count += 1
    
    return count
```
