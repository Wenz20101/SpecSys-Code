You can convert a tuple of positive integers into a single integer by concatenating the digits of each number in the tuple. Here's a Python function that does that:

```python
def tuple_to_integer(t):
    """
    Converts a tuple of positive integers into a single integer.
    
    Parameters:
    t (tuple): A tuple of positive integers.
    
    Returns:
    int: The concatenated integer.
    """
    result = ""
    for num in t:
        result += str(num)
    return int(result)
```

### Example usage:

```python
t = (12, 34, 56)
print(tuple_to_integer(t))  # Output: 123456
```

### Notes:
- This function assumes that all elements in the tuple are positive integers.
- If the tuple is empty, it will return `0` (you may want to handle that case depending on your needs).
