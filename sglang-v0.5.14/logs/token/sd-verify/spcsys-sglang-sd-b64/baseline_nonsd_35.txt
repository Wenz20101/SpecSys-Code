You can write a Python function to calculate the frequency of all elements in a list and return the result as a dictionary using the `collections.Counter` class, which is efficient and clean. Here's how you can do it:

```python
from collections import Counter

def get_element_frequency(input_list):
    """
    Returns a dictionary with the frequency of each element in the input list.

    Parameters:
    input_list (list): A list of elements (can be of any hashable type).

    Returns:
    dict: A dictionary where keys are elements from the list and values are their frequencies.
    """
    return dict(Counter(input_list))
```

### Example Usage:

```python
my_list = ['apple', 'banana', 'apple', 'orange', 'banana', 'apple']
frequency = get_element_frequency(my_list)
print(frequency)
```

### Output:

```python
{'apple': 3, 'banana': 2, 'orange': 1}
```

### Notes:
- This function works for any hashable elements (e.g., integers, strings, tuples).
- If you want to avoid using `collections`, you can also implement it manually with a dictionary:

```python
def get_element_frequency(input_list):
    frequency = {}
    for item in input_list:
        if item in frequency:
            frequency[item] += 1
        else:
            frequency[item] = 1
    return frequency
```
