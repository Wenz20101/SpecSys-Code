A **monotonic array** is one that is either entirely non-increasing or non-decreasing. That is, the elements either never increase or never decrease as you move from left to right.

Here's a Python function to check whether a given array is monotonic:

```python
def is_monotonic(arr):
    """
    Check if the given array is monotonic (either non-increasing or non-decreasing).
    
    Parameters:
    arr (list): The input list to be checked.
    
    Returns:
    bool: True if the array is monotonic, False otherwise.
    """
    if not arr:
        return True  # An empty array is considered monotonic

    increasing = True
    decreasing = True

    for i in range(1, len(arr)):
        if arr[i] > arr[i - 1]:
            decreasing = False
        elif arr[i] < arr[i - 1]:
            increasing = False

    return increasing or decreasing
```

### Example usage:

```python
print(is_monotonic([1, 2, 2, 3]))  # True (non-decreasing)
print(is_monotonic([6, 5, 4, 4, 3]))  # True (non-increasing)
print(is_monotonic([1, 3, 2, 4]))  # False (not monotonic)
print(is_monotonic([]))  # True (empty array)
```

### Explanation:
- The function checks whether the array is **non-increasing** or **non-decreasing**.
- It uses two flags: `increasing` and `decreasing`.
- If at any point the array increases, the `decreasing` flag is set to `False`.
- If at any point the array decreases, the `increasing` flag is set to `False`.
- At the end, if either flag is still `True`, the array is monotonic.
