Here's a Python function that finds the **next smallest palindrome** of a given integer. A **palindrome** is a number that reads the same forward and backward (e.g., 121, 1331).

### Function: `next_smallest_palindrome(n)`

This function will:
- Start from `n + 1`
- Check each number in order to see if it's a palindrome
- Return the first one that is

### ✅ Example:
```python
next_smallest_palindrome(123)  # returns 131
next_smallest_palindrome(121)  # returns 131
next_smallest_palindrome(999)  # returns 1001
```

---

### ✅ Python Code:

```python
def is_palindrome(num):
    return str(num) == str(num)[::-1]

def next_smallest_palindrome(n):
    if n < 0:
        raise ValueError("Input must be a non-negative integer.")
    next_num = n + 1
    while True:
        if is_palindrome(next_num):
            return next_num
        next_num += 1
```

---

### 🔍 Explanation:

- `is_palindrome(num)` checks if a number is a palindrome by comparing the string to its reverse.
- `next_smallest_palindrome(n)` starts from `n + 1` and checks each number in sequence until it finds the next palindrome.
