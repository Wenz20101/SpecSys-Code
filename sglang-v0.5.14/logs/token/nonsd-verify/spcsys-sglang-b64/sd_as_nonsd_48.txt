Sure! To find the **kth element** in a given array using **1-based indexing**, you can simply access the element at index `k - 1` in Python, since Python uses **0-based indexing**.

Here's a Python function that does this:

```python
def find_kth_element(arr, k):
    """
    Find the kth element in the array using 1-based indexing.

    Parameters:
    arr (list): The input array.
    k (int): The position (1-based) of the element to retrieve.

    Returns:
    any: The kth element of the array.

    Raises:
    IndexError: If k is out of bounds.
    """
    if k < 1 or k > len(arr):
        raise IndexError("k is out of bounds of the array")
    return arr[k - 1]
```

### Example usage:

```python
arr = [10, 20, 30, 40, 50]
k = 3
print(find_kth_element(arr, k))  # Output: 30
```

### Notes:
- This function assumes that `k` is a positive integer.
- It raises an `IndexError` if `k` is less than 1 or greater than the length of the array.
