Sure! Here's a Python function that converts a string into a list of strings, splitting on the space character:

```python
def split_string_by_space(input_string):
    """
    Splits the input string into a list of substrings based on spaces.

    Parameters:
    input_string (str): The string to be split.

    Returns:
    list: A list of substrings split by spaces.
    """
    return input_string.split()
```

### Example usage:

```python
result = split_string_by_space("Hello world this is a test")
print(result)
```

### Output:
```
['Hello', 'world', 'this', 'is', 'a', 'test']
```

### Notes:
- The `split()` method without any arguments automatically splits on any whitespace (including multiple spaces, tabs, newlines, etc.).
- If you want to split **only** on single spaces and not other whitespace, you can use `split(' ')` instead, but be cautious of leading/trailing spaces and multiple spaces.
