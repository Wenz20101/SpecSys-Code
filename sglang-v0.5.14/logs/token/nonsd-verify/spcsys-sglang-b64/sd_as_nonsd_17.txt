Sure! Here's a Python function that counts the number of **positive numbers** in a list:

```python
def count_positive_numbers(numbers):
    """
    Count the number of positive numbers in a list.

    Parameters:
    numbers (list): A list of integers or floats.

    Returns:
    int: The count of positive numbers in the list.
    """
    count = 0
    for num in numbers:
        if num > 0:
            count += 1
    return count
```

### Example usage:

```python
nums = [1, -2, 3, 0, 4.5, -7, 8]
print(count_positive_numbers(nums))  # Output: 4
```

### Explanation:
- The function iterates through each number in the list.
- It checks if the number is **greater than 0** (i.e., positive).
- It increments the count for each positive number.
- Finally, it returns the total count.
