Sure! Here's a Python function that counts the number of `True` boolean values in a given list:

```python
def count_true_booleans(boolean_list):
    """
    Counts the number of True boolean values in the given list.

    Parameters:
    boolean_list (list): A list containing boolean values (True/False).

    Returns:
    int: The count of True values in the list.
    """
    return sum(1 for item in boolean_list if item is True)
```

### Example usage:

```python
my_list = [True, False, True, True, False]
print(count_true_booleans(my_list))  # Output: 3
```

### Explanation:
- The function uses a generator expression inside the `sum()` function.
- It iterates over each item in the list and adds `1` for every item that is `True`.
- `item is True` ensures that only actual `True` boolean values are counted, not values that evaluate to `True` (like non-zero numbers or non-empty strings).
